# Phased Python rewrite — grill log

Decisions from sequential grill-with-docs sessions. Spec: [`2026-05-17-phased-python-rewrite-design.md`](./2026-05-17-phased-python-rewrite-design.md).

| Round | Question (summary) | Decision |
|-------|-------------------|----------|
| 1 | Phase 1 image behavior when config has `support_image: true` and legacy `image` rows exist | **(C)+(A):** At cutover set `support_image: false` on all active question types in YAML; Phase 1 API always returns `images: []` on reads; submit with non-empty `images` → 400 `本提问箱不支持图片上传`; legacy DB/COS data kept but carousels empty until a later image phase. |
| 2 | Phase 1: persist `question.ip` on submit vs defer to Phase 2 (`origin/main` has no `ip` column; unmerged WIP is not contract baseline) | **Defer to Phase 2:** Phase 1 matches `origin/main` Go — no `ip` column, no `ip_geo` table usage, no IP capture, no `ip`/`ip_addr`/`ip_isp` in any JSON. Phase 2 adds schema + ADR-0001 capture + geolocation + admin-only fields. Contract `MUST` goldens assert keys omitted. |
| 3 | Unanswered `answered_at` in DB is NULL — JSON `null`, omit key, or epoch sentinel? | **Epoch sentinel:** When `answered_at` IS NULL, serialize `"answered_at": "1970-01-01T00:00:00Z"` (Go `time.Unix(0,0)` + RFC3339). Never `null` or omitted. Visit enqueue only when parsed instant ≠ epoch zero (same as Go `!= time.Unix(0,0)`). Golden fixtures include unanswered + answered rows. |
| 4 | Rename `GET /owner` JSON field `owner` (it is admin JWT uuid, not Owner slug)? | **Keep `owner` key, uuid value:** Byte-for-byte parity with `auth_handler.GetOwnerInfo` (`c.GetString("uuid")`). Catalog row documents “legacy key name = admin session UUID”. Owner slug only in route params and list/submit bodies. |
| 5 | Visit async: flush interval, crash loss, SQLite write pattern? | **10s flush (configurable), tolerate ≤1 interval loss on crash, idempotent incr:** `asyncio` queue + in-memory merge by uuid (sum counts, latest timestamp) + `ON CONFLICT DO UPDATE` upsert per uuid. Matches Go `VisitMonitor` intent; Go uses SELECT/batch UPDATE — Python upsert is allowed if semantics match. |
| 6 | Keyword filter match on submit — HTTP status? | **Stealth 200:** Insert with `deleted_at` set; response `200` `{uuid, asked_at}` identical to clean submit. Asker can still `GET /questions/question`; owner list excludes row. `MUST` golden: `submit_keyword_filtered.json`. |
| 7 | Contract tests: full catalog vs minimum `MUST` golden set first? | **Historical migration decision:** `go-api-behavior.md` listed every route/edge (incl. `PHASE-2` rows). During cutover planning, `MUST` rows were gated by Go golden tests. After promotion, the Go backend is deprecated and current validation is Python pytest plus manual smoke. |
| 8 | Go + Python sharing SQLite during testing — dual writers? | **Never dual-write prod DB:** ADR-0003 — one writer per file. Parity/soak uses **copies** (`contract.db`, ephemeral test DB) or read-only attach. Prod cutover: stop Go writer before Python owns the file. |
| 9 | Phase 1 deploy: nginx big-bang vs blue-green? | **Big-bang upstream swap:** Change `proxy_pass` to Python port (or socket), reload nginx; brief acceptable downtime. No dual upstream / traffic split. Rollback = revert `proxy_pass` + restart Go on prior port. |
| 10 | Prod secrets in yaml vs env; expose FastAPI `/docs` in prod? | **Env overrides for secrets:** `JWT_SECRET_KEY`, `MAGIC_SPELL` (and Phase 2 `DEEPSEEK_API_KEY` if any) from environment; YAML holds non-secret config only. **`/docs` and `/redoc` denied in prod** via nginx `location` (default deny); dev may allow locally. |
| 11 | Phase 2 geolocation failure → omit `ip_addr` or empty? Legacy `image`/COS rows in P1? | **Fail-open empty string:** Persist `question.ip` on submit; background lookup best-effort; on skip/failure/timeout admin JSON has `ip_addr: ""` (JOIN miss), not omitted. **P1 no purge:** Do not delete `image` rows or COS objects; reads return `images: []` (R1). |
